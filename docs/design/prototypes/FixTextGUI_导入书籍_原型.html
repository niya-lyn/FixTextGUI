2.4.3 底线① · 只读保护 + 人话提示

导入安全说明

▶
  • 导入即把书复制到内部工作区，绝不直接修改你原来的文件（验收①「原文件字节不被修改」）。
  • 编码自动识别（UTF-8 / GBK / GB18030），转换时以人话提示，不出现任何命令行窗口（§2.2 入口② 验收①）。
  • EPUB 导入不暴露 spine / OPF 等内部概念（§2.2 入口① 验收③）。
勾选「显示设计依据」可看到每个 UI 元素对应的文档条款，证明不是把命令面板直接包装成产品。
