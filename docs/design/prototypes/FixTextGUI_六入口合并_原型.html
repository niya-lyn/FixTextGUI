§2.7.8 · 失败兜底留痕

快照与恢复

恢复到任意时间点▶
  • 每次处理前自动创建快照，任一快照可完整恢复现场并重新导出。
  • 基准同步失败不阻断主流程，仅在历史记录中留痕（状态列标记）。
  • 恢复与单条删除均可撤销；清理全部历史不可恢复（均需二次确认）（2.4.3 底线）。
勾选「显示设计依据」可看到每个 UI 元素对应的文档条款。清理历史是破坏性操作，必须显式触发 + 二次确认（§2.2 入口⑥ 验收③）。
