# FixText V1 合并版原型 · 更新记录

> 唯一源：`UI/prototypes/FixText_V1_合并版_原型.html`（单文件，浏览器直接打开）。后续只改原型，除非声明"QT 骨架修改"。

## 0. 基线：合并为单一源
- 7 份分模块原型合并为单文件唯一源；旧源归档至 `_archive/2026-10-27_consolidation/`。

## 1. 质感打磨
- 统一质感语言：分层阴影、平滑过渡、顶栏渐变、焦点环、遮罩虚化；大屏收束布局 + 表格斑马纹；表单聚焦光晕 + 卡片级联动画。

## 2. 对齐仓库实现
- 左轨仅 6 入口 + 底注；顶栏 ☰/?/⚙ 三按钮；词库页头浅色控件变体；保留前几轮优化。

## 3. 新增功能：新手向导
- 把骨架只读向导平移为原型中"真实引导一本书校准"的三步向导（导入→校正→导出），含 ☰ 菜单触发、首-run 自动弹；并迭代加入跳过、返回上一步、按钮左右分栏、校正取消二次确认等交互。

## 4. 空状态整改
- 去掉空状态收起按钮；词库页无空状态；补一键校正/导出两页空状态；5 处空状态统一双按钮居中。

## 5. 交互 bug 修复
- 修复检查页卡片折叠无反应（折叠判定对象错误，导致内容始终隐藏）。
- 修复一键校正排版选择无反应（选择结果未正确回写，导致下拉/输入选了不生效）。

## 6. 多书工作区与书架打磨
- 支持一次导入多本，并在书架中选择"当前要校对的书"；顶栏与校正/检查/导出页随之联动显示书名与导出路径。
- 选择入口收敛到「导入书籍」：顶栏"当前书"改为只读标牌，点击跳转导入书架去切换，其它页面只展示不提供切换（用户约束）。
- 顶栏"当前书"原文字与底色对比不足几乎不可读，改为高对比胶囊 + 可点击态与状态指示，并打磨悬停/聚焦质感。
- 书架状态精简：只保留"已导出"标识，去掉"已导入/已校正/未导入"等冗余状态。
- 书架"设为当前"做成主操作按钮，与"当前"标识区分；并改为右侧固定宽度对齐，避免点击切换时状态文字发生位移。

## 7. 一键校正选项与设置调整
- 「替换引擎」从一键校正高级选项移入「设置」，成为全局校正引擎配置（与一键校正共用）。
- 高级选项「使用哪套词库」由单选下拉改为多选勾选，勾选项与「词库管理」的词库完全一致（我的词库 / 常规校正 / 标点规范 / 繁简转换），可任意组合。
- 「设置」中移除「显示设计依据」开关（属原型标注演示能力，非真实产品功能；各页面顶部仍保留原型标注入口）。
- 一键校正高级选项新增「自动修复引号问题」开关（默认关闭）：开启后引号类问题在校正阶段自动修复。
- 「开始校正」弹窗不再自动关闭，按开关分支文本：关→"检出引号问题 N 处"；开且仍有剩余（M>0）→"已自动修复 N 处，剩余 M 处待人工确认"并附「去检查页」按钮；开且全部修复（M=0）→"已自动修复 N 处"，隐藏「去检查页」按钮。

## 8. 检查问题页状态机重构
- **书源条**：改为显示当前书（书名 + 类型），去掉"已校正"前提，状态文案随页态动态变化。
- **四态状态机**：空态（无书→引导导入）→ 待检查（「开始检查」）→ 检查中（进行中）→ 结果态（逐处处理）；补 0 检出的「检查通过」态。
- **一态一键**：顶部单一主按钮随状态切换文案/样式（开始检查 / 取消 / 重新检查），删除原「只统计不修复」「结束检查」两按钮，收敛为单一入口；结果态统计条复用同一重查运行态。
- **批量卡**：补「按已启用规则修复全部」，走预览影响条数 + 二次确认。
- **规则 #6** 改名：「按文件类型补右引号」→「补右引号」（段落末尾补缺失右引号）。

## 9. 组件排序与空状态治理
- **排序原则（四层）**：每页按「控制区（入口/状态常驻顶）→ 核心工作区（主操作/逐处处理）→ 辅助区（批量/规则旁路）→ 参考区（纯说明/只读）」排布组件。
- **检查页**：问题清单与编辑器左右并排（窄屏堆叠）；"检查项（自动执行）"说明卡移至底部参考区。
- **导入/导出**：导入安全说明卡移至结果槽下方（参考区）；导出「开始导出」置顶、结果槽紧随、替换报告置底（参考区）。首页/校正/词库/历史/设置已符合，未动。
- **空状态**：4 处保留页面底部并标注 §2.2 入口②/③/⑤/⑥（校正/检查/导出/历史），并修复有数据时仍显示的矛盾横幅（接入数据长度判断）；导入页因"拖放区+说明区+导入后工作区"已完整闭环，移除原空状态。
- **预览开关**：顶栏「预览空状态」演示开关（非真实功能）临时清空数据以查看不可达空态，关闭后恢复；配合顶部「显示设计依据」开关才显示条款标注。
- **前提**：原型无删书交互、默认有书，空状态为规格预留态，正常路径不可达，保留以符合规格并可在演示时查看。

## 10. 样式打磨：视觉一致性专项（按优先级分节）

> 范围：纯视觉样式打磨，**不改动任何功能与交互逻辑**（遵循通用约定）。以下按改动影响面分高 / 中 / 低三档，每档独立一节。
> 验证方式：本环境无法直接查看截图，统一采用 `getComputedStyle` 探针 + Chromium `--dump-dom` 读取客观计算样式值验证（禁用态 opacity/cursor/`pointer-events`、暗色令牌反转、关键对比度），并做 CSS 括号平衡 / div 开合 / 无重复 id / 图标 symbol 定义与引用一致性校验——全部通过。

### 高优先级（全局地基与主题）

- **Step 1 · 样式地基收口**（上轮完成）：修 3 个未定义令牌（`--c-primary-bg`→`--c-primary-50`、`--c-primary`→`--c-primary-600`、`--c-surface`→`--c-neutral-0`）；合并 10 组重复冲突定义（`.page-head`/`.main`/`.c-body`/`.frow`/`.note`/`.toast`/`.modal`/`.mask`/`.diff`/`.legend`），保留语义正确的一份；约 40 处 `#fff`→`var(--c-neutral-0)`。
- **Step 2 · 色彩收敛**（上轮完成）：清除色板外硬编码（`#7c5cff`→主色系、`#7FE3B0`→success 系、`#1C2230`/`#10141B`→neutral 系、`#FFF6E9`→warning-bg 等）；焦点环统一 `--sh-focus`；裸 `rgba` 阴影统一 `--sh-primary`；启用空转令牌 `--c-focus`/`--lh-*`/`--fw-*`。
- **Step 3 · 图标系统统一**：文件顶部建 29 个 `<symbol>` 雪碧图（24×24、`stroke=currentColor`、`fill=none`、圆头圆角线性风格）+ 全局 `.ic` 类；约 140 处彩色 emoji / `▶` / `×` 全量替换为单色内联 SVG（尺寸继承容器、颜色继承 `currentColor`，随文字色自动变化）；`mainBtn`/ONB_STEPS/wstep 模板由 `textContent`→`innerHTML` 改造以渲染 SVG；保留 6 处 `.dot` 的 `✓` 字形（文本节点无法承载 SVG 标记）。
- **Step 8 · 暗色模式**：基于 `:root` 加 `[data-theme="dark"]` 与 `@media (prefers-color-scheme: dark)` 双层覆盖；neutral 阶梯反转（`--c-neutral-0` 表面随主题变深、`--c-neutral-900` 顶栏保持最暗）；primary 适度提亮；success/warning/error/info 的 `bg`/`border` 降饱和为半透明 tint；`--sh-*` 加深；`.topbar` 渐变锚定 `--c-neutral-900` 保持暗色（修正原渐变误用会反转为浅色的 `--c-neutral-800`）；`.toast` 改用随主题反转的 `--c-surface-inv`（浅色回退 `--c-neutral-800`，观感不变）；`.mini-input` 补令牌背景/前景以适配暗色。

### 中优先级（交互与状态层）

- **Step 4 · 页面头部分级统一**：合并 3 处冲突的 `.page-head` 为单一规范（`align-items:flex-end` + `border-bottom` 分隔）；`.chk-top` 与 `.hero` 的大按钮 `padding`/`gap`/规格完全对齐；渐变主操作横幅仅保留「校正 `.hero` / 检查 `.chk-top` / 导出 `.hero`」3 页，其余 5 页走统一 page-head。
- **Step 5 · 交互三态统一**：统一过渡时长（`.12s`）与焦点环（`--sh-focus`）为整套键盘可达交互元素；补 `active` 下沉（`.btn.danger`/`.btn.ghost`/`.nav-item`/`.radio`/`.link-btn`/`.drop`/`.demo-btn`/`.prow`/`.chk`/`.card .c-head`/`.close-x`，`btn-primary-lg` 用 `scale(.99)`）；补 `.switch`/`.close-x`/`.card .c-head` 的 hover；`.switch` 补齐 hover/active/focus 三态。
- **Step 6 · 禁用 / 只读 / 锁定统一**：定义一套 disabled 语言 `opacity:.5` + `cursor:not-allowed` + 按钮 `pointer-events:none`；统一 `.btn:disabled`（`.45→.5`）、两处 `btn-primary-lg:disabled`（`.6→.5`）、`.diff .del`（`.8→.5`）；`.chk.locked` 删除反直觉的 hover 变主色，改为中性弱化（整体 `opacity:.7` + neutral 边框/底色，hover 不再高亮）；`.lock-tag` 由主色实心强调改为中性弱化胶囊；新增 `.ro-tag` 只读标识（信息色弱胶囊）与 `.switch.disabled` 禁用变体。

### 低优先级（局部增强）

- **Step 7 · 空状态视觉升级**：4 处 `.empty-state` 统一版式——图标区加柔和图标环（`--c-primary-50` 6px 光晕 + 软投影）、标题 `--fs-md`/semibold、说明 `--fs-sm`/`--c-neutral-500`、dashed 边框由中性-300 改为中性-200 更柔和、padding/圆角统一；§2.2 入口标注 tag 保留不动（仅视觉，标注逻辑不变）。
