# FixText V1 合并版原型 · 更新记录

> 唯一源：`UI/prototypes/FixTextGUI_合并版_原型.html`（单文件，浏览器直接打开）。后续只改原型，除非声明"QT 骨架修改"。

## 0. 基线：合并为单一源
- 7 份分模块原型合并为单文件唯一源；旧源归档至 `_archive/2026-10-27_consolidation/`。

## 1. 质感打磨
- 统一质感语言：分层阴影、平滑过渡、顶栏渐变、焦点环、遮罩虚化；大屏收束布局 + 表格斑马纹；表单聚焦光晕 + 卡片级联动画。

## 2. 对齐仓库实现
- 左轨仅 6 入口 + 底注；顶栏 ☰/?/⚙ 三按钮；词库页头浅色控件变体；保留前几轮优化。

## 3. 新增功能：新手向导
- 把骨架只读向导平移为原型中"真实引导一本书校准"的三步向导（导入→校正→导出），含 ☰ 菜单触发、首-run 自动弹；并迭代加入跳过、返回上一步、按钮左右分栏、校正取消二次确认等交互。

## 4. 空状态整改
- 去掉空状态收起按钮；词库页无空状态；补一键校正/导出两页空状态；5 处空状态统一双按钮居中。

## 5. 交互 bug 修复
- 修复检查页卡片折叠无反应（折叠判定对象错误，导致内容始终隐藏）。
- 修复一键校正排版选择无反应（选择结果未正确回写，导致下拉/输入选了不生效）。

## 6. 多书工作区与书架打磨
- 支持一次导入多本，并在书架中选择"当前要校对的书"；顶栏与校正/检查/导出页随之联动显示书名与导出路径。
- 选择入口收敛到「导入书籍」：顶栏"当前书"改为只读标牌，点击跳转导入书架去切换，其它页面只展示不提供切换（用户约束）。
- 顶栏"当前书"原文字与底色对比不足几乎不可读，改为高对比胶囊 + 可点击态与状态指示，并打磨悬停/聚焦质感。
- 书架状态精简：只保留"已导出"标识，去掉"已导入/已校正/未导入"等冗余状态。
- 书架"设为当前"做成主操作按钮，与"当前"标识区分；并改为右侧固定宽度对齐，避免点击切换时状态文字发生位移。

## 7. 一键校正选项与设置调整
- 「替换引擎」从一键校正高级选项移入「设置」，成为全局校正引擎配置（与一键校正共用）。
- 高级选项「使用哪套词库」由单选下拉改为多选勾选，勾选项与「词库管理」的词库完全一致（我的词库 / 常规校正 / 标点规范 / 繁简转换），可任意组合。
- 「设置」中移除「显示设计依据」开关（属原型标注演示能力，非真实产品功能；各页面顶部仍保留原型标注入口）。
- 一键校正高级选项新增「自动修复引号问题」开关（默认关闭）：开启后引号类问题在校正阶段自动修复。
- 「开始校正」弹窗不再自动关闭，按开关分支文本：关→"检出引号问题 N 处"；开且仍有剩余（M>0）→"已自动修复 N 处，剩余 M 处待人工确认"并附「去检查页」按钮；开且全部修复（M=0）→"已自动修复 N 处"，隐藏「去检查页」按钮。

## 8. 检查问题页状态机重构
- 书源条改为显示当前书（书名 + 类型），去掉"已校正"前提；状态文案随页面状态动态变化（空 / 待检查 / 检查中 / 结果）。
- 四态状态机：空态（无书→引导去导入）→ 待检查（主按钮「开始检查」）→ 检查中（进行中）→ 结果态（逐处处理页）；并补 0 检出的「检查通过」态。
- 一态一键：顶部栏单一主按钮跟随页面状态切换文案与样式——待检查态亮「开始检查」、检查中变「取消」、结果态变「重新检查」；删除原「只统计不修复」「结束检查」两个按钮，收敛为单一操作入口。
- 结果态统计条新增「重新检查」，复用同一运行态。
- 批量操作卡补「按已启用规则修复全部」，走现有的预览影响条数 + 二次确认样式。
- 规则 #6 改名：「按文件类型补右引号」→「补右引号」，描述改为"在段落末尾补上缺失的右引号"。
