# FixText V1 · 导航模型与视觉令牌统一决策

> 日期：2026-10-26 ｜ 范围：薄地基设计系统 + 6 个模块交互原型（词库管理 / 一键校正 / 导入书籍 / 检查问题 / 导出结果 / 历史记录）
> 背景：三份产物在导航模型、顶栏、颜色/字体/圆角令牌上出现漂移，需定一种并回灌对齐。
> 更新：6 入口已全部产出独立交互原型，共用同一导航外壳与令牌源。

---

## 一、导航模型：定「全程侧栏 + 首页概览」

**决策**：Qt / 全部界面统一采用 **左侧常驻 6 入口轨 + 内容区** 的单框架；原「首页 6 卡片」降级为内容区里的 **概览页**。

**映射规则**
| 元素 | 含义 |
|---|---|
| 左侧常驻轨（6 入口等权） | 全局导航骨架，任何模块都可见、可一键跳模块 |
| 顶部品牌 logo「FixText」 | 点击回到首页概览（6 卡片） |
| 内容区 | 概览页 / 各模块视图，随轨切换而不换 chrome |

**为什么不采用「首页卡片进模块后切侧栏」**
1. FixText 是**流水线工具**（导入→校正→检查→词库→导出→历史，用户会反复横跳），常驻轨让模块间零返回摩擦。
2. 切侧栏会造成 **chrome 模式切换**，丢失「我在哪」的位置感。
3. 要维护「首页布局」+「侧栏布局」两套导航代码，增加实现与走查成本。

**当前落地**：词库管理原型、一键校正原型本就采用左侧轨 + 顶栏 + 内容区；薄地基首页 6 卡片改为该框架内的概览页，三份文件现已共享同一导航 chrome。

## 二、视觉令牌：薄地基 `:root` 为唯一源

**治理规则**
- `FixTextGUI_设计系统_薄地基.html` 的 `:root` 是**唯一令牌源**，颜色 / 字体 / 圆角不得在任何其他文件另行定义。
- 各原型把地基 `:root` **逐字复制**进自身；类样式**直接使用地基命名**（`--c-neutral-800`、`--r-md`…），**不设别名层**。
- 真实 Qt 交付时，地基令牌应抽成共享 QSS/SCSS 被全局 `@import`，原型里的复制块仅作离线预览用途。

**漂移对照表（旧原型值 → 地基唯一源值）**
| 令牌 | 旧原型值 | 地基值 | 类别 |
|---|---|---|---|
| `--c-primary-700` | `#333C8C` | `#333B83` | 主色深档 |
| `--c-primary-600` | `#3F49A8` | `#3F48A2` | 主色中档 |
| `--c-primary-50` | `#F6F7FD` | `#EEF0FB` | 主色最浅 |
| `--c-success` | `#1F9D6B` | `#15803D` | 语义·成功 |
| `--c-warning` | `#C9820A` | `#B45309` | 语义·警告 |
| `--c-error` | `#D8453B` | `#C0392B` | 语义·错误 |
| `--c-info` | `#2F7FD8` | `#3F48A2` | 语义·信息 |
| 字体 | `Inter` 优先 | `Segoe UI` 优先 | 中文本地化首选 |
| 圆角 | `6/10/14`（`--r-s/m/l`） | `4/8/12`（`--r-sm/md/lg`） | 圆角体系 |

**命名空间治理（局部别名 → 地基令牌）**
| 原型局部名 | 映射到 |
|---|---|
| `--c-ink / --c-ink-2 / --c-ink-3` | `--c-neutral-800 / 600 / 500` |
| `--c-line / --c-line-2` | `--c-neutral-200 / 100` |
| `--c-bg / --c-surface` | `--c-neutral-50 / 0` |
| `--r-s / --r-m / --r-l` | `--r-sm / --r-md / --r-lg` |
| `--sh-1 / --sh-2 / --sh-3` | `--sh-sm / --sh-md / --sh-lg` |
| `--fz-12…20` | `--fs-xs…xl` |

> 说明：上表映射已作为**一次性批量改名**落地——6 个原型的类样式现在直接使用地基命名（`.nav-item` 用 `--c-neutral-600`、`--r-md`），别名层已删除，因此**改一处地基值即全产品生效**，不再有隐藏的第二套色板。上表仅作历史对照留档。

## 三、品牌顶栏：定「深中性（neutral-900）」

**决策**：顶栏统一使用 `var(--c-neutral-900)`（深中性、近黑），不使用 `primary-700`。

**理由**
- FixText 是作者长时间盯文本校正的工具，顶栏应 **内容优先**：深中性把视觉重量压到内容区，靛蓝只在按钮 / 选中态等**操作层**出现，不喧宾夺主。
- 长会话下深中性比大面积主色更不易产生色彩疲劳。
- 与薄地基原始设定一致，回灌成本低、不引入新变量。

**备选**：若后续要更强的品牌识别，可整体切换为 `primary-700` 顶栏——只需改三份文件的 `.topbar` 背景一处即可（已用变量，无散落硬编码）。

### 原型组织方式（本轮拍板）
采用 **一模块一文件**（共 6 个独立 HTML），每份自带完整 chrome（顶栏 + 左轨 + 首页概览 + 本模块 + 其余 5 个占位页）。
- 选择理由：与已交付的两个原型保持一致；每个模块可独立评审、独立替换，不互相牵连。
- 占位页已升级：不再显示「功能页待扩展」，而是直接指出该模块的独立原型文件名，6 份文件之间可互相索引。
- 未采用：整合为单文件全互跳（会改动已交付的 2 个原型）、跨文件 `file://` 链接。

**已闭环（本轮）**
- 局部命名已直接改名回地基令牌（如 `--c-ink → --c-neutral-800`、`--r-m → --r-md`），6 个原型内不再存在第二套命名；`:root` 注释同步更新。
- 导航方案已在全部 HTML 中落地：左侧常驻 6 入口轨 + 首页概览内容页，品牌点击回首页；6 个原型默认进入首页概览，点击入口切模块、chrome 不变。
- 一键校正展开「排版规范化（可选）+ 高级选项」后低分辨率被裁切的根因（grid 子项缺 `min-height:0`）已修复，内容改为内部滚动并显示滚动条；4 个新原型均继承该修复。
- 6 入口全部产出全交互原型（mock 数据 + 真实 toggle/视图切换/进度/二次确认/撤销），内容逐条对应需求文档 §2.2 与 §2.7.3~2.7.8。
- 全部 7 份 HTML 通过标签平衡校验（0 未闭合、0 错误），令牌纯净度 grep 通过。

**Qt 交付阶段（第一步已落地）**
- ✅ 令牌单一来源：`fixtext_tokens.py`（与薄地基 `:root` 逐字对应）→ `build_qss.py` 生成 `fixtext.qss`。QSS 不支持 CSS 变量，故由生成器把令牌值展开进样式；改令牌只需改令牌模块后重跑 `build_qss.py`。原型的 `:root` 复制块自此仅作离线预览。
- ✅ chrome 收敛：`main_window.py` 以单一 `MainWindow` + `QStackedWidget` 承载「顶栏 + 左轨 + 首页概览 + 6 模块」，默认进首页概览；点左轨或首页卡片切页、品牌点击回家、左轨 `active` 属性驱动高亮。6 份 HTML 各自复制的 chrome 由这一处替代。
- 已用 PySide6 6.12（offscreen）做过冒烟测试：`stack.count == 7`、页面键齐全、`go()` 切换与左轨高亮正确；并渲染出 `Qt骨架_首页概览.png` / `Qt骨架_检查问题.png` 双图验证 QSS 生效。
- ✅ 复用部件库 `fixtext_widgets.py`：`Card`（可折叠 + 设计依据标签）、`Switch`（胶囊开关）、`Pill`（状态徽标）、`FieldRow`（编号+名称+描述+控件）、`hline`——全部只消费令牌，不硬编码色值。
