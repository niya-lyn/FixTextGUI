# FixTextGUI · 已知缺口

当前版本功能可用，但以下事项**尚未完成或未经充分验证**，使用前请知悉。

## 功能层面

1. **导出 EPUB 未做主流阅读器真机确认**：导出在开发环境做了结构与内容校验，没有在
   Kindle / Apple Books / 微信读书等阅读器上逐一验证「导入即读」。建议第一次使用时先
   导出一本，用自己常用的阅读软件打开检查。
2. **查重弹窗本身只读（有意设计，不是缺陷）**：词库「查重」弹出的清单只供查看，底部
   只有「关闭」，不会在弹窗里直接改词库；处理重复请用工具条上的「合并」「删除选中」
   （各自先预览、二次确认、可撤销）。
3. **取消不是瞬时中断**：点取消后界面会显示「正在取消…」。文字替换大约一秒内结束；
   排版在**当前章**结束后停下；其它步骤要等当前这一步跑完。取消后本次中间结果会清掉，
   不留半成品。
4. **不附带示例书**：请直接导入自己的 TXT / EPUB 试用（新手向导也会引导你选自己的书）。
5. **中文校对依赖词库覆盖**：出厂 304,255 条规则来自上游 PHP 项目的 map 词库，对网络
   小说常见的错别字替换、乱标点覆盖较好；专业领域文本、古籍异体字等场景未做专项验证，
   需要自行补充自定义词条。

## 环境层面

6. **杀毒软件**：已在微软 Defender 与火绒上验证绿色版（命令行 / 自检 / 冒烟 + 自定义
   查杀），未发现威胁、未隔离。其它杀软或其它机器仍可能误报；若被拦截，请把整个
   FixTextGUI 文件夹加入白名单后重新解压，并把现象反馈出来。
7. **macOS 明示不支持**：完整校正链路只覆盖 Windows 与 Linux；在 Mac 上启动会弹出提示。
   包内无 macOS 替换引擎，一键校正不可用。
8. **「Windows 已保护你的电脑」**：绿色版若未购买代码签名，首次运行可能出现该提示；
   点「更多信息」→「仍要运行」即可（详见《使用说明（绿色版）.txt》）。

## 已经解决的旧缺口

- ~~首次运行向导只读演示~~ → 向导已改为真实三步（导入 → 校正 → 导出）。
- ~~取消只能等整段排版结束~~ → 排版已在章节边界响应取消。
- ~~未提供打包版 / Windows 未真机~~ → 已有 Windows 绿色包，构建机自检通过。
