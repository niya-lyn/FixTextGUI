```

```

即 `app.exec()` 在窗口关闭后返回 0，进程正常终止。

### A2 · 门禁清单与 CI 脚本随工程交付 —— 通过

- `docs/code-review-gates.md`：收录 3.5 四条固定检查项（G1 闭包单独测试 / G2 strictMap 按数据清洗 / G3 闭包显式检测报警 / G4 禁用 flashtext 与 iter_long），每条含要求、依据、评审动作、不通过示例；另含骨架结构约定 S1–S4 与每 MR 必填的评审记录表。
- `scripts/ci.py`（+ `scripts/ci.bat` Windows 双击入口）：一键执行 lint → format-check → gates → tests。
- `scripts/check_gates.py`：把 G4 与 S1 落成机器可判定检查。
- `.github/workflows/ci.yml`：Linux + Windows 双平台流水线。

### A4 · Windows 10/11 真机验证 —— 未验证

**本环境为 Linux 容器，无 Windows 真机，无法执行该项。**

已做的替代保障：

1. 工程侧不依赖 Linux 专有路径：`common/paths.py` 按 `sys.platform` 分支处理 `%LOCALAPPDATA%` / `%APPDATA%`；
2. CI 脚本用 Python 实现（`scripts/ci.py`），不使用 bash 专有语法，Windows 侧由 `scripts/ci.bat` 直接调用；
3. `.github/workflows/ci.yml` 已配置 `windows-latest` 矩阵任务，但本环境无法触发该流水线。

**风险说明**：Windows 上的实际启动行为（含 PySide6 wheel 安装、GUI 平台插件加载、中文路径与编码）未经真机确认。该项须在具备 Windows 10/11 的环境执行 `python scripts\ci.bat` 与 `python scripts\smoke_launch.py` 后补齐。
