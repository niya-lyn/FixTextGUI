FixText V1 · 使用说明

三步上手 · 遇到问题先翻这一页

1解压与启动

  1. 找到发行压缩包 FixText_V1.zip，右键 → 全部解压（或「解压到 FixText_V1\」）。
  2. 打开解压后的文件夹，确认里面包含启动程序 FixText.exe、fixtext_ui\、pipeline\ 等目录。
  3. 双击 FixText.exe 启动。首次打开会弹出「新手向导」，跟着三步演示走完即可开始使用。
绿色便携版：不写注册表、不改系统设置，整个文件夹可随意复制、移动或删除。

若你拿到的是源码包而非打包 exe，请先装好 Python 3.11+，再运行根目录的 main_app.py。

2Windows 首启 SmartScreen 警告

第一次运行未经签名的发行版时，Windows 会弹出蓝色 SmartScreen 拦截框，这是正常现象，不代表软件含病毒。

为什么会这样？ 应用尚未向 Microsoft 提交代码签名证书、且发布时间较短，SmartScreen 对「未知发布者」默认拦截——属于 Windows 的内置保护机制，并非查杀到威胁。
  1. 在 SmartScreen 对话框中点击 更多信息（或「详细信息」）。
  2. 按钮会变成 仍要运行，点击它即可放行。
  3. 应用随后正常启动；同一版本首次通过后，短期内一般不再拦截。
若系统杀毒软件（如 Windows Defender / 第三方卫士）也拦截，请把 FixText.exe 所在文件夹加入白名单 / 信任区。仍不放心可对照发布页提供的文件哈希自行校验。

3关于桌面快捷方式

本版不会在桌面自动创建快捷方式——我们刻意保持「下载即用、不留痕迹」，不替你往系统里塞东西。

  1. 想要一键启动？在资源管理器里右键 FixText.exe → 发送到 → 桌面快捷方式。
  2. 或启动后右键任务栏图标 → 固定到任务栏，以后从任务栏直接打开。
  3. 也可把解压文件夹固定到「快速访问」，方便随时进入。
