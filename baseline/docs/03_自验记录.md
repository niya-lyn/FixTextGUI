## §4 上游一致性验证（深度验证，可选）

命令：`php baseline/scripts/verify_upstream_equivalence.php <上游FixText/src目录> ./baseline`

```

A2 after  数组逐元素一致: 是

== B. PHP 后端：上游 TextFixer::replaceByPHP（反射） vs expected/php ==
B1 上游 replaceByPHP 输出 == 包内 expected/php: 是
B2 上游 replaceByPHP 输出 == 包内 expected/go : 是
B  判定: PASS
== C. PHP 直连配置（REPLACE_BY_GO=false） vs expected/go ==
  [pg24264_紅樓夢.txt] C 配置输出 == expected/go: 是
  [novel_guimie_full.txt] C 配置输出 == expected/go: 是
  [pg27166_呐喊.txt] C 配置输出 == expected/go: 是

```

三项验证的含义：

- **A**：包内规则集来自上游真实 `Map::flattenMaps`（含 Go 语义的排序），304,256 条规则逐元素一致；
- **B**：以反射调用上游真实 `TextFixer::replaceByPHP`（Go 降级路径语义），输出与冻结基线逐字节一致；
- **C**：`REPLACE_BY_GO=false` 的 PHP 直连配置（未排序 flattenMaps）输出同样与 expected/go 一致——证明三条生产执行路径等价（详见 `02_基线方法论.md`）。
